Ce viewer se connecte à l'écran d'une VM QEMU tournant sur TA machine (pas sur un serveur distant) via VNC/WebSocket. Il n'affiche rien tant que tu n'as pas :

1. Lancé la VM avec le port WebSocket exposé :
./vm/test-vm.sh --iso ton.iso --vnc-websocket 5959

2. Exposé ce port publiquement (ex. avec ngrok) :
ngrok http 5959

3. Collé l'URL wss:// obtenue ci-dessus et cliqué "Connecter".

Détails complets : voir docs/REMOTE_VIEWER.md dans le dépôt du projet.
